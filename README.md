# Shino Manabe profile site

A single-page editorial profile for Shino Manabe, built as a lightweight static site.

## Preview locally

```bash
npm run dev
```

Open `http://localhost:4173`.

## Content updates

- Replace the image assets in `assets/images/` while keeping their filenames to update them without touching the markup.
- The green workshop panel in `index.html` contains an `EDITABLE` comment showing where a future workshop photograph can be added.
- Profile copy is grouped by theme rather than as a full résumé.

Open Sauce Sans is included under the SIL Open Font License; see `assets/fonts/OFL.txt`.
